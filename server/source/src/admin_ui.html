使用说明

1. 上传证书：把 keybox.xml 拖到下方上传区（只需这一个文件，私钥和证书链会自动解析）。
2. 打开本地出证：右上角开关打开后，服务器就用自己的 keybox 直接签发证书（server_keybox 模式）；关闭则走 A/B 端转发真实 TEE（physical 模式）。
3. 管理 Token：下方「API Token 管理」板块可生成 A/B 端接入令牌。
4. 看结果：下方表格实时显示已存身份、在线 B 端、任务和报告。
